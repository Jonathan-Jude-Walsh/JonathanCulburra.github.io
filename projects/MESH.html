MESH – Modular Economical Sonobuoy Heuristic

Low-Cost Passive Acoustic Detection and Classification System

Project Overview

MESH is a low-cost passive acoustic surveillance project focused on detecting and classifying marine vessels in shallow-water environments. The system combines hydrophone instrumentation, embedded DSP, Raspberry Pi processing, and lightweight machine-learning techniques to evaluate practical vessel detection under realistic coastal conditions.

The project investigates trade-offs between hardware cost, acoustic performance, computational load, and power consumption while supporting scalable autonomous maritime monitoring concepts.

Project Objectives

  • Develop a low-cost hydrophone acquisition chain.
  • Implement embedded DSP on Raspberry Pi hardware.
  • Evaluate acoustic vessel classification techniques.
  • Perform laboratory and coastal field experiments.
  • Assess power, cost, and performance trade-offs.
